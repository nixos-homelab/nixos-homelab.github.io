    actualBudgetSyncMap attribute set of (string or (submodule)) { } Map of Actual Budget account names to Ghostfolio account names, use an …

    homelab.ghostfolio.actualBudgetSyncMap

    Map of Actual Budget account names to Ghostfolio account names, use an attrSet for extended options

    Default

    { }

    Example

    {
  ActualBudgetAccountName = "GhostfolioAccountName";
  Cash = "Liquid Assets";
  Investments = {
    factor = 7.45;
    ghostfolioName = "Liquid Assets";
  };
}

    Declared in nix/modules/ghostbudget/default.nix
    debug boolean false Whether to enable debug mode.

    homelab.ghostfolio.debug

    Whether to enable debug mode.

    Default

    false

    Example

    true

    Declared in nix/modules/ghostbudget/default.nix

    Whether to enable Ghostfolio.

    true
