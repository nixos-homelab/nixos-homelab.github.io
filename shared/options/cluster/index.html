cluster

homelab.cluster

Name Type Description
backup.hostPaths list of string List of paths on the host that should be backed up, this option does not configure a backup, it is only meant for aggregation
backup.volumes attribute set of attribute set of list of string A map of namespace -> PV claim name -> paths that should be backed up, this option does not configure a backup, it is only meant for aggregation
debugTools list of package Tools to embed in container images when debugging is enabled
enableIPv4 boolean IPv4 support
enableIPv6 boolean Whether to enable IPv6 support.
imageLocks attribute set of list of string The image refs each lock file of lib.images.locked and lib.images.chart pins, by its path, for lock-images to re-lock them when what names them changes
images list of package Container images to preload on the node, so that nothing is pulled at runtime
kubeconfig string Path of a kubeconfig with admin rights on the node, as the runner writes it. Set by the runner.
kubernetesVersion string The Kubernetes version the cluster runs (1.35.8). Set by the runner.
manifests attribute set of (submodule) Manifests for the runner to apply, by name. The runner deletes what a manifest stops holding, so an object stays in the manifest it was in.
manifests..content null or (attribute set) or list of (attribute set) Objects of the manifest: one, or a list of them
manifests..enable boolean Whether the runner applies this manifest
manifests..source absolute path A YAML file of the manifest, in place of content
payload package A directory of the manifests as the runner applies them; build nixosConfigurations.<host>.config.homelab.cluster.payload to look at them. Set by the runner.
podCidr4 string IPv4 CIDR for the pods
podCidr6 string IPv6 CIDR for the pods
providedComponents list of (one of "ingress", "load-balancer", "metrics-server") Cluster components a module deploys itself, so the runner leaves out the one it may bundle
runtimeCRDs list of absolute path CustomResourceDefinition files of resources whose CRDs no manifest carries, as an operator creates them at runtime (a CNI's), for the manifests check to validate those resources against
sourceLocks attribute set of attribute set of package The fetches each lock file of lib.pins.locked pins, by its path and their key, without their hash, for lock-images to lock them when a pin changes
svcCidr4 string IPv4 CIDR for the services
svcCidr6 string IPv6 CIDR for the services
unit string The systemd unit that runs the cluster, for units that need the API to order after. Set by the runner.
