    logs.formats.<name>.stages strings concatenated with "\n" — loki.process stages that parse a record.

    homelab.alloy.logs.formats.<name>.stages

    loki.process stages that parse a record. They leave message in the extracted map (the line otherwise stays whole), level with the raw level, and other fields either under their canonical names (homelab.alloy.logs.fields) or under f.<raw name>. A program sets the label of that name, for containers that run several programs. Match the message with (?s) so it keeps the lines of a multiline record.

    monitors attribute set of (submodule) { } What Alloy scrapes, a ServiceMonitor each.

    homelab.alloy.monitors

    What Alloy scrapes, a ServiceMonitor each. A module with metrics sets its own here (importing this module) and gets scraped exactly when Alloy is on: no flag per monitor. Every target gets a node label, the node of the pod behind it; the rest are the operator's (namespace, service, pod, container, endpoint, job, instance), and a target's own labels of those names are kept as exported_<name>.

    Default

    { }
