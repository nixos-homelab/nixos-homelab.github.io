    alerting.contactPoints attribute set of list of (submodule) { } Where notifications go: each contact point a list of Grafana …

    homelab.grafana.alerting.contactPoints

    Where notifications go: each contact point a list of Grafana integrations (email, webhook, telegram, pushover, ...). Secrets stay out of here: a setting can name an environment variable as $NAME, which Grafana expands from environmentSecrets. An integration naming one that is unset is left out until it is set, and the routes to a contact point left without integrations with it.

    Default

    { }

    Example

    {
  phone = [
    {
      type = "webhook";
      settings.url = "$NOTIFY_URL";
    }
  ];
}

    dashboards attribute set of (submodule) { } Dashboards Grafana provisions, read-only in its UI.

    homelab.grafana.dashboards

    Dashboards Grafana provisions, read-only in its UI. A module adds its own in a grafana.nix next to it; the builders in this flake's lib.grafana write the v2 resource format (dashboard.grafana.app/v2). Each is a ConfigMap of its own, mounted without subPath, so a change reaches Grafana without a restart.

    Default

    { }

    Example

    {
  disks.dashboard = ./disks.json;
  nas.dashboard = with inputs.homelab-monitoring.lib.grafana; dashboard {
    name = "nas";
    title = "NAS";
    layout = autoGrid { } [
      (stat {
        title = "Up";
        queries = [ (prom "up{job=\"node-exporter\"}" { instant = true; }) ];
      })
    ];
  };
}
