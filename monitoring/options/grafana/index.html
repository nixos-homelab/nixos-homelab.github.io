    Name Type Default Description
    apiServerAccess boolean false Whether to enable the API server's service proxy reaching Grafana's web …

    homelab.grafana.apiServerAccess

    Whether to enable the API server's service proxy reaching Grafana's web port. Grafana trusts the login headers of whatever reaches it, and the proxy forwards a client's headers, so whoever may get services/proxy on grafana can read Grafana as any user. Meant for short-lived checks .

    Default

    false

    Example

    true

    Declared in nix/modules/grafana/default.nix
    dashboards attribute set of (submodule) { } Dashboards Grafana provisions, read-only in its UI.

    homelab.grafana.dashboards

    Dashboards Grafana provisions, read-only in its UI. A module adds its own in a grafana.nix next to it; the builders in this flake's lib.grafana write the v2 resource format (dashboard.grafana.app/v2). Each is a ConfigMap of its own, mounted without subPath, so a change reaches Grafana without a restart.

    Default

    { }

    Example

    {
  disks.dashboard = ./disks.json;
  nas.dashboard = with inputs.homelab-monitoring.lib.grafana; dashboard {
    name = "nas";
    title = "NAS";
    layout = autoGrid { } [
      (stat {
        title = "Up";
        queries = [ (prom "up{job=\"node-exporter\"}" { instant = true; }) ];
      })
    ];
  };
}

    overviews.<name>.panels attribute set of (submodule) { } The panels.

    homelab.grafana.overviews.<name>.panels

    The panels. Those with an order under 100 are tiles: they fill strips of up to eight at the top, the tiles of a strip sharing its width, so w doesn't matter for them. The rest are packed onto Grafana's 24-column grid below, in order (lower first, then by name), each where it sits highest. Modules keep their panels together by their orders: 100 to 199 for the first module, and so on.

    Default

    { }

    Metrics one module provides and other modules' panels use, by what they mean rather than where they come from: a function from a PromQL label selector (node="$node", or "") to the query, null while no module provides it.
